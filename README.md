# ScamShield India AI

ScamShield India AI is a multilingual fraud-awareness platform built using Google's Gemini models.

## Features

- Scam Detection
- PDF Analysis
- Screenshot Analysis
- Fraud Knowledge Base
- Risk Scoring Engine
- English Support
- Hindi Support
- Punjabi Support
- Downloadable Reports

## Built With

- Python
- Streamlit
- Gemini AI
- SQLite
- Pandas
- ReportLab

## Use Cases

- Fake Job Offers
- Internship Scams
- Scholarship Scams
- UPI Frauds
- KYC Frauds
- Lottery Scams
- Phishing Attempts
